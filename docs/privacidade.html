Política de privacidade / Privacy policy

Este app é uma ferramenta pessoal usada apenas pelo dono das contas “Nino” para publicar os próprios vídeos e ver as métricas das próprias contas no Instagram, YouTube e TikTok.

Dados usados: o acesso (token) que a própria pessoa autoriza, guardado criptografado; as métricas públicas e de desempenho dos próprios vídeos. Nenhum dado de terceiros é coletado, vendido ou compartilhado. Para remover o acesso, basta revogar o app nas configurações de cada rede; os dados guardados são apagados em seguida.

This is a personal tool used only by the owner of the “Nino” accounts to publish their own videos and read the metrics of their own Instagram, YouTube and TikTok accounts. It stores only the access token the owner authorizes (encrypted) and performance data of the owner's own videos. No third-party data is collected, sold or shared. Revoking the app in each platform's settings removes access, and stored data is then deleted.

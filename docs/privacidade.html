Política de privacidade / Privacy policy

Este app é uma ferramenta pessoal usada apenas pelo dono das contas “Nino” para publicar os próprios vídeos e ver as métricas das próprias contas no Instagram, YouTube e TikTok.

Dados usados: o acesso (token) que a própria pessoa autoriza, guardado criptografado; as métricas públicas e de desempenho dos próprios vídeos. Nenhum dado de terceiros é coletado, vendido ou compartilhado. Para remover o acesso, basta revogar o app nas configurações de cada rede; os dados guardados são apagados em seguida.

This is a personal tool used only by the owner of the “Nino” accounts to publish their own videos and read the metrics of their own Instagram, YouTube and TikTok accounts. It stores only the access token the owner authorizes (encrypted) and performance data of the owner's own videos. No third-party data is collected, sold or shared. Revoking the app in each platform's settings removes access, and stored data is then deleted.

YouTube API Services

This app (“Robo Nino”) uses YouTube API Services to upload the owner's own videos to the owner's own YouTube channel and to read that channel's statistics. By using this app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What we access, store and why: an OAuth refresh token (stored encrypted with AES-GCM in a private-key vault in the owner's own GitHub repository) to upload scheduled videos; the IDs, titles and statistics (views, likes, comments) of the owner's own videos, stored as a daily metrics file so the owner can compare performance. Nothing is shared with third parties, sold, or used for advertising.

Retention and deletion: stored YouTube data is refreshed daily and kept no longer than 30 days unless refreshed. You can revoke the app's access at any time at Google security settings (third-party access); after revocation the stored token and YouTube data are deleted within 7 days. Deletion can also be requested by opening an issue.

Cookies: this app does not use cookies or tracking, and does not place or read information on users' devices.
